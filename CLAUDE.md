# Claude Code Project Rules

## File Creation Rules

- NEVER create temporary files with names like `tmpclaude-*` or similar patterns
- NEVER create files for debugging, testing, or temporary purposes in the project directory
- If temporary files are needed, use the system temp directory instead
- Always clean up any files created during operations

## General Guidelines

- Prefer editing existing files over creating new ones
- Keep changes minimal and focused on the task at hand
